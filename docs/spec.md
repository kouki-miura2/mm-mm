A note-taking tool that lets you save and organize notes by category.  
カテゴリごとにメモを登録・管理するツール。

## 総論

### 目的

<!-- 誰の、どんな課題を、どう解決するかを1〜2文で。 -->

ユーザーは規約とプライバシーポリシーを確認・同意した後、Googleでログインすることで利用開始できる。  
メモを管理したいレベルでカテゴリを定義し、そのカテゴリにキーワードとメモを登録していく。  
メモはカテゴリごとに検索でき、目的のキーワードやメモ文字列を簡単に見つけることができる。  
PWAとして動作し、データはIndexedDBに同期することで、Cloudflare-D1へのクエリ回数や読み取り行数を削減する。

### 利用イメージ

<!-- 代表的な利用の流れを、場面ごとに操作の順で書く。 -->

- カテゴリ追加
  - メモを管理する単位=カテゴリを追加する
  - カテゴリ名は後で変更することができる
- メモ追加
  - カテゴリの中に、キーワードとメモを追加する
  - キーワードは任意で、キーワードを省略した場合はメモの先頭N文字（「リミット値」参照）をキーワード欄に表示する
  - キーワードおよびメモは後で変更することができる
- メモ検索
  - カテゴリの中で、テキスト入力によりキーワードおよびメモを部分一致で検索できる
  - 検索結果は一覧で表示され、内容を確認したあと、検索結果に戻り、別の検索結果を再確認できる

- 一般公開するサービスとする

### カテゴリ管理機能

- カテゴリを登録・変更・削除する
- カテゴリ削除は、削除前に確認を行い、論理削除とする

#### 項目

| 項目       | 備考                                   |
| ---------- | -------------------------------------- |
| カテゴリ名 | 必須。文字数の上限は「リミット値」参照 |
| 表示順     | カテゴリ一覧に表示する順番             |

#### 画面

- 表示する内容
  - カテゴリ一覧
- 操作
  - カテゴリを選択する
  - 編集モードにするとカテゴリの表示順をドラッグ&ドロップで変更する

#### 一覧

- 並び順は「表示順」とする。

#### 登録・変更・削除

- 登録：20件（「リミット値」参照）まで登録できる
- 変更：カテゴリ名を変更できる
- 削除：メモが含まれる場合は、確認ダイアログを表示した後、論理削除する

### メモ管理機能

- メモを登録・変更・削除する
- メモ削除は、削除前に確認を行い、論理削除とする

#### 項目

| 項目       | 備考                                                                                                                      |
| :--------- | :------------------------------------------------------------------------------------------------------------------------ |
| キーワード | 任意。文字数の上限は「リミット値」参照。キーワードを省略した場合はメモの先頭N文字（「リミット値」参照）をキーワードとする |
| メモ       | メモ本文。必須。文字数の上限は「リミット値」参照                                                                          |
| 表示順     | キーワード・メモを表示する順番                                                                                            |

#### 画面

- 表示する内容
  - メモ一覧（2カラム表示）
    - 下記2カラム表示とし、境界線はドラッグで左右に移動できる（左側・右側の最小幅（「リミット値」参照）より狭くはできない）
    - 左側=キーワード
    - 右側=メモ本文
    - キーワードとメモ本文は上揃えで横に並ぶように配置する
  - メモ一覧（1カラム表示）
    - すべてのキーワードを1行で表示し、タップするとダイアログでキーワードとメモの詳細を確認できる
- 操作
  - メモを参照する
  - メモ一覧編集モードにすると、メモの表示順をドラッグ&ドロップで変更する
  - メモ編集モードにすると、キーワード、メモ本文をそれぞれ編集できる

#### 一覧

- 並び順は「表示順」とする。

#### 登録・変更・削除

- 登録：300件（「リミット値」参照）まで登録できる
- 変更：キーワード・メモ本文を変更できる
- 削除：確認ダイアログを表示した後、論理削除する

### データ保持・プライバシー

- 論理削除されたカテゴリは、1か月後に物理削除する（カテゴリに含まれるメモも物理削除する）
- 論理削除されたメモは、1か月後に物理削除する

### 設定機能

- 登録カテゴリ数の確認
- カテゴリごとの、登録メモ数の確認
- アプリのインストール（インストール済みの場合は表示しない）
  - ブラウザがインストール画面を表示できる場合（Chrome・Edge など）は、その画面を表示する
  - 表示できない場合（iOS・Safari など）は、ホーム画面への追加手順を表示する
- 利用規約・プライバシーポリシーの確認
- アプリバージョンの確認
- CSVダウンロード
  - 選択したカテゴリ（すべて、または複数）のすべてのキーワード、メモ本文をCSV形式でダウンロードする
- 退会
  - 確認ダイアログ表示後、そのユーザーのすべてのカテゴリ、すべてのメモを物理削除する

### データ仕様

仕様を満たす最小限のデータを保持する。導出できる値は都度集計する。

- 各テーブルの `id` は `crypto.randomUUID()` で生成する。
- 日時はすべて UTC の UNIX エポックミリ秒（INTEGER）で保持する。表示時に Asia/Tokyo に変換する（「総論 > 提供形態」参照）。
- `created_at`・`updated_at`・`deleted_at` はサーバーの時刻で設定する。
- カテゴリ・メモ・セッションの読み書きは、すべてログイン中のユーザーの `user_id` で絞り込む（「総論 > 権限」参照）。

#### Cloudflare D1

##### users（ユーザー）

Googleアカウント1つにつき1行。同意の後に登録する（「総論 > 共通ルール」の「同意」参照）。

| カラム          | 型      | 備考                                                                             |
| --------------- | ------- | -------------------------------------------------------------------------------- |
| id              | TEXT    | PK                                                                               |
| google_sub      | TEXT    | Google の ID トークンの `sub`。UNIQUE。メールアドレス・氏名は保持しない          |
| terms_version   | TEXT    | 同意した利用規約・プライバシーポリシーの版。現行の版と異なる場合は再同意を求める |
| terms_agreed_at | INTEGER | 同意日時                                                                         |
| created_at      | INTEGER | 登録日時                                                                         |

##### sessions（セッション）

ログイン中であることを表す。有効期限は「リミット値」参照。

| カラム     | 型      | 備考                                                                   |
| ---------- | ------- | ---------------------------------------------------------------------- |
| token_hash | TEXT    | PK。セッショントークンの SHA-256。トークン自体は保持しない             |
| user_id    | TEXT    | FK → users                                                             |
| expires_at | INTEGER | 有効期限。期限切れの行はリクエスト時に無効とし、定期処理で物理削除する |
| created_at | INTEGER | 登録日時                                                               |

- INDEX: `(user_id)`（退会時の削除用）

##### categories（カテゴリ）

| カラム     | 型      | 備考                                                         |
| ---------- | ------- | ------------------------------------------------------------ |
| id         | TEXT    | PK                                                           |
| user_id    | TEXT    | FK → users                                                   |
| name       | TEXT    | カテゴリ名                                                   |
| sort_order | INTEGER | 表示順（昇順）                                               |
| created_at | INTEGER | 登録日時                                                     |
| updated_at | INTEGER | 更新日時。登録・変更・表示順の変更・論理削除のたびに更新する |
| deleted_at | INTEGER | 論理削除日時。NULL 可（NULL は未削除）                       |

- INDEX: `(user_id, updated_at)`（ユーザーごとの取得・差分同期用）
- INDEX: `(deleted_at)` WHERE `deleted_at IS NOT NULL`（定期処理の物理削除用。論理削除された行だけを含む）

##### memos（メモ）

| カラム      | 型      | 備考                                                                                       |
| ----------- | ------- | ------------------------------------------------------------------------------------------ |
| id          | TEXT    | PK                                                                                         |
| user_id     | TEXT    | FK → users。カテゴリから導出できるが、差分同期と権限の絞り込みを JOIN なしで行うために持つ |
| category_id | TEXT    | FK → categories                                                                            |
| keyword     | TEXT    | キーワード。NULL 可（省略時。表示時にメモ本文の先頭から切り出す。「リミット値」参照）      |
| body        | TEXT    | メモ本文                                                                                   |
| sort_order  | INTEGER | カテゴリ内の表示順（昇順）                                                                 |
| created_at  | INTEGER | 登録日時                                                                                   |
| updated_at  | INTEGER | 更新日時。登録・変更・表示順の変更・論理削除のたびに更新する                               |
| deleted_at  | INTEGER | 論理削除日時。NULL 可（NULL は未削除）                                                     |

- INDEX: `(user_id, updated_at)`（差分同期用）
- INDEX: `(category_id, deleted_at)`（カテゴリごとの取得・件数判定・全件同期用）
- INDEX: `(deleted_at)` WHERE `deleted_at IS NOT NULL`（定期処理の物理削除用。論理削除された行だけを含む）

##### 削除・件数の扱い

- カテゴリを論理削除しても、含まれるメモの `deleted_at` は設定しない。論理削除されたカテゴリのメモは表示しない。
- 物理削除は定期処理で行う。`deleted_at` から「リミット値」の期間を過ぎたカテゴリは、含まれるメモとあわせて物理削除する。メモも同様に単独で物理削除する。
- 登録件数の上限（「リミット値」参照）は、論理削除されていない行だけを数える。
- 表示順の変更では、順番が変わった行だけ `sort_order` を書き換える。

##### 同期（D1 → IndexedDB）

- 画面はIndexedDBのデータを表示し、D1からは前回の同期以降に変更された行だけを取得する。
- 差分の取得: クライアントは前回サーバーから受け取った同期時刻を送り、サーバーは `updated_at` がそれ以降のカテゴリ・メモ（論理削除された行を含む）と、新しい同期時刻を返す。
- 前回の同期時刻が物理削除までの期間（「リミット値」参照）より古い場合、または初回は、全件を取得してIndexedDBを置き換える（物理削除された行は差分に現れないため）。
- 同時更新はあと勝ちとする（「総論 > 共通ルール」参照）。更新はオンライン時にAPIへ送り、成功した結果をIndexedDBへ反映する。

#### DBの外で管理するデータ

- **セッショントークン:** ログイン時に発行し、`HttpOnly`・`Secure`・`SameSite=Lax` の Cookie で保持する。画面のスクリプトからは読めない。
- **カテゴリ・メモの複製と同期時刻:** ブラウザのIndexedDBに保持する（「同期（D1 → IndexedDB）」参照）。ログアウト時に削除する。
- **利用規約・プライバシーポリシーの現行の版:** 画面とAPIのコードに定数で持つ。
- **メモ一覧の境界線の位置・表示形式（1カラム／2カラム）:** 端末ごとの設定として localStorage に保持する。
